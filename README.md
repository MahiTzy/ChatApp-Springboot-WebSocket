# Real-Time Chat Application — Spring Boot WebSocket

A Java application exploring real-time messaging with Spring Boot and WebSocket technology.

## Overview
This repository contains the backend implementation for a chat application. Review the WebSocket configuration, message models, controllers, and frontend/client assets (if included) to understand connection handling and message delivery.

## Technology
- Java
- Spring Boot
- WebSocket support and dependencies declared by the project

## Getting Started
1. Install a compatible JDK.
2. Clone the repository:
   ```bash
   git clone https://github.com/MahiTzy/ChatApp-Springboot-WebSocket.git
   cd ChatApp-Springboot-WebSocket
   ```
3. Review the build file and application configuration.
4. Configure any required external services.
5. Run with the Maven wrapper if present (`./mvnw spring-boot:run`) or use the configured build tool.

## Real-Time Communication
Inspect the configured WebSocket endpoint, message formats, and event handlers to determine how clients connect and exchange messages. Endpoint details are not assumed here.

## Security
Review origin restrictions and authentication before exposing a WebSocket endpoint publicly. Do not commit credentials or secrets.
